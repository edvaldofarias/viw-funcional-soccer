# Fixtures Copa Fácil

Exemplos sintéticos construídos a partir dos formatos observados em duas edições. Nomes, IDs, datas e URLs são fictícios; não são cópias integrais das respostas. `historical.json` mostra súmula sem presença e metadados antigos; `current.json` inclui presença, relógio e partida com participantes pendentes; `recorded-null-score.json` exercita a regra informada pelo responsável. Na próxima etapa, os testes do adaptador usarão esses arquivos. Não tratá-los como catálogo completo dos códigos do provedor.
